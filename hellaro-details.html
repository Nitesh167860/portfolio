Hellaro Fashion Mall

Project Overview

Hellaro Fashion Mall is a full-featured fashion e-commerce web application built with React, TypeScript, Vite and Supabase. It provides a complete shopping experience with product browsing, product variants, dynamic product images, cart, wishlist, checkout and customer accounts. The platform also includes coupon support, order tracking, notifications, returns/exchange, responsive design and an admin management system for products, categories, brands, orders and storefront content.
